# ✦ PeoplePulse
### Attendance Analytics API

**Turn everyday attendance records into clear, reliable workforce insights.**

A Python, FastAPI, and MongoDB backend for employee attendance management and workforce analytics—designed around explicit business rules, efficient database queries, and results that can be explained.

> Clear rules. Efficient queries. Results you can explain.

## ✨ Overview

PeoplePulse transforms attendance records into useful workforce insights. It provides endpoints for employee management, attendance tracking, regularization, monthly summaries, department analytics, lateness rankings, and daily attendance trends.

The project emphasizes three core principles:

- **Correctness:** Consistent attendance calculations, time handling, and input validation.
- **Efficiency:** MongoDB indexes and aggregation pipelines for data-intensive analytics.
- **Clarity:** Readable code, explicit design decisions, and query-plan inspection.

## 🧰 Tech Stack

- Python
- FastAPI
- MongoDB
- PyMongo
